# CLAUDE.md

## General rules

- Keep changes minimal and focused.
- Do not redesign unrelated parts of the application.
- Use plain JavaScript compatible with OpenLayers 7.
- Reuse existing styles and theme variables.
- Do not add dependencies without asking.
- Do not replace working code with large abstractions.
- Explain the cause before proposing a fix.
- Prefer small patches over full rewrites.
- All code, comments, and configuration files must be in English.
- No hardcoded values. Read structure, schema, and conventions from the project's own files.
- No over-engineering. Only change what was explicitly asked. No refactoring, no extras, no improvements beyond the request.
- When in doubt: ask before changing.
- If a task can be done in two ways, pick the simpler one.
